# Isla Food

Site de apresentação do Isla Food, o ecossistema de delivery da Island Company para lanchonetes, hamburguerias, pizzarias, restaurantes e lojas de açaí.

- Página estática (HTML, CSS e JS sem build), publicada na Vercel.
- `index.html`: o site completo, com SEO, dados estruturados (Organization, WebSite, SoftwareApplication e FAQPage) e o orçamento que envia a mensagem pronta para o WhatsApp.
- `img/` e `media/`: imagens e vídeos do produto.
- `robots.txt` e `sitemap.xml`: indexação no Google.
